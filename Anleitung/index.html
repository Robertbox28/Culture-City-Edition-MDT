Das Mobile Data Terminal

Wie du das überarbeitete MDT installierst, einstellst und im Dienst benutzt. Für Polizei, Rettungsdienst, Feuerwehr, Justiz, Regierung, Taxi und Mechaniker.

02Installation

  1. Sichern. Kopiere deinen bisherigen Ordner ps-mdt an einen sicheren Ort.
  2. Ersetzen. Lösche die alten Ordner ps-mdt und ps-dispatch auf dem Server und kopiere die beiden Ordner aus dem ZIP an dieselbe Stelle.
  3. Reihenfolge in der server.cfg prüfen. ps-mdt muss nach seinen Abhängigkeiten starten: 
    ensure oxmysql
ensure qb-core
ensure ps-dispatch
ensure lb-phone
ensure ps-mdt
  4. Datenbank. Die neue Tabelle mdt_assignments für die Besetzung legt sich beim ersten Start selbst an. Sie steht zusätzlich in mdt.sql, falls du sie lieber von Hand anlegst.
  5. Neu laden. In der Server-Konsole: 
    refresh
restart ps-dispatch
restart ps-mdt
    refresh ist nötig, weil das Manifest neue Dateien enthält.

Bestehende Daten der Feuerwehr wurden früher unter ambulance gespeichert und bleiben beim EMS. Neue LSFD-Einträge werden als fire gespeichert. Einzelne alte Einträge kannst du per SQL umstellen, zum Beispiel UPDATE mdt_reports SET jobtype='fire' WHERE id IN (...).

Taxi und Mechaniker

Beide haben eine schlanke Oberfläche nur für ihre eigene Arbeit. In den Profilen sehen sie weder Geburtsdatum, Wohnung und Fingerabdruck noch Lizenzen, Vorstrafen oder Haftbefehle. Vorfälle, Waffen, Kameras und die Zulassungsstelle sind gesperrt, auch auf dem Server. Sie haben einen eigenen Funk und sehen keine Einsätze und Einheiten der Behörden.

Rechtsklick nutzen

  • Auf deinem Namen unter „Aktive Einheiten“: Dienststatus, Rufzeichen und Funkkanal setzen.
  • Auf einem Einsatz: ausrücken, abmelden, Wegpunkt setzen oder Notruf beantworten.
  • Auf Pinnwand, Berichten und BOLOs: Einträge löschen.
  • Taxi und Mechaniker: auf einem offenen Auftrag annehmen, abgeben oder Wegpunkt setzen.

05Besetzung

Die Besetzung zeigt, wer mit wem in welchem Fahrzeug unterwegs ist. Jede Behörde hat ihre eigene Einteilung. Alle Polizeibehörden teilen sich eine.

  1. Neu klicken und einen Funkrufnamen eingeben, zum Beispiel Adam-12 oder Engine 7-1.
  2. Fahrzeug wählen oder mit Mein aktuelles Fahrzeug übernehmen Modell und Kennzeichen automatisch eintragen.
  3. Rechts unter Personal auf Namen klicken, um sie der Einheit zuzuteilen. Wer schon eingeteilt ist, wechselt beim Speichern automatisch.
  4. Status setzen: Verfügbar, Im Einsatz, Pause oder Ausser Dienst.
  5. Speichern. Alle derselben Behörde sehen die Änderung sofort.

Einteilung zurücksetzen leert die ganze Liste, zum Beispiel beim Schichtwechsel. Zum Schutz vor Versehen braucht das einen zweiten Klick.

06Vorfälle und Anklagen

  1. Unter Vorfälle mit dem Plus einen neuen Vorfall anlegen. Die Vorlage füllt sich automatisch.
  2. Unter Beteiligte Kriminelle die Person hinzufügen.
  3. Rechtsklick in das Feld unter der Person, dann Anklagen bearbeiten.
  4. Im Katalog links klicken fügt eine Anklage hinzu, rechts klicken entfernt sie. Empfohlene Busse und Haft werden addiert.
  5. Status setzen (Haftbefehl, Schuldig, Bearbeitet), dann mit Gefängnis, Busse oder Sozialstunden vollziehen und speichern.

Aufträge für Taxi und Mechaniker

Taxi und Werkstatt haben einen eigenen Auftrags-Dispatch, getrennt von Polizei und Rettung.

BefehlGeht anPopup und Karte
/taxi [Nachricht]Alle Taxifahrer im Dienst (Gruppe TAXI)Gelb, Code TAXI, Taxi-Symbol
/mechaniker [Nachricht]Alle Mechaniker im Dienst (Gruppe MECH)Gelb im East-Customs-Stil, Code MECH, Schraubenschlüssel
  • Die Nachricht ist freiwillig. Ohne Text wird ein Standardsatz gesendet.
  • Wer anruft, braucht ein Telefon. Zwischen zwei Bestellungen liegen 60 Sekunden (Config.ServiceCallCooldown).
  • Name und LB-Phone-Nummer des Kunden stehen im Auftrag.
  • Mit E nimmt der Fahrer oder Mechaniker den Auftrag an und bekommt den Wegpunkt. Im MDT stehen die Aufträge unter „Offene Aufträge“ und auf der Karte.
  • Taxi und Werkstatt sehen nur ihre eigenen Aufträge, Polizei und Rettung sehen sie nicht.
  • Für eine Handy-App oder andere Skripte: exports['ps-dispatch']:TaxiCall(nachricht) und exports['ps-dispatch']:MechanicCall(nachricht).

Die Jobs der Gruppen stehen in ps-dispatch/config.lua unter Config.AuthorizedJobs.TAXI und Config.AuthorizedJobs.MECH.

Anwälte hören mit

Anwälte (lawyer) bekommen alle Einsätze, die an Polizei oder Feuerwehr gehen: Popup, Kartenpunkt und Anzeige im MDT. Das Popup ist braun und mit „Justiz · mithören“ beschriftet. Anwälte werden nicht als Einheit an Einsätze angehängt. Einsätze, die nur an den Rettungsdienst gehen, sehen sie nicht.

Wer mithört, steht in ps-dispatch/config.lua:

Config.DispatchListeners = {
    ['lawyer'] = { 'LEO', 'FIRE' },
}

Was sich geändert hat

  • Einsätze im MDT: Bisher sahen nur die Jobs police und ambulance die Einsätze im MDT. Jetzt sehen sie alle Jobs der Gruppen, also auch LSPD, BCSO, SASP, DOC und LSFD.
  • Deutsch: Meldungen, Kartenpunkte, Fahrzeugfarben, Fahrtrichtung, Geschlecht und Hinweise sind auf Deutsch. Tempo in km/h.
  • Popup: Neues Design passend zum MDT, Farbe je Behörde (Polizei blau, EMS rot, LSFD orange). Mit E fährst du den Einsatz an, solange das Popup sichtbar ist.
  • Telefonnummer: Bei /911 und /311 kommt die Nummer aus LB Phone. Anonyme Anrufe bleiben unterdrückt.
  • Einheiten: Im MDT stehen angehängte Einheiten als Polizei, EMS oder LSFD.
  • Fehler behoben: /togglealerts hat nie funktioniert, beim Abhängen vom Einsatz entstanden Lücken in der Einheitenliste, und 311 erschien auf der Karte als 911.

Eigene Alarme aus anderen Skripten

exports['ps-dispatch']:CustomAlert({
    coords = GetEntityCoords(PlayerPedId()),
    message = "Einbruch in Lagerhalle",
    dispatchCode = "10-90",
    description = "Einbruch in Lagerhalle",
    priority = 2,
    job = { "LEO" },   -- oder { "EMS", "FIRE" }
})

Neue Jobs immer an zwei Stellen eintragen: in ps-mdt/shared/config.lua und in ps-dispatch/config.lua.

09Fehlerbehebung

ProblemLösung
Neue Seiten oder Dateien fehlenrefresh vor restart ps-mdt ausführen. Ohne refresh kennt der Server die neuen Dateien nicht.
Besetzung bleibt leerIn der Server-Konsole nach SQL-Fehlern suchen. Notfalls die Tabelle mdt_assignments aus mdt.sql von Hand anlegen.
Telefonnummer fehlt oder ist altlb-phone muss vor ps-mdt starten. Mit Config.PhoneSystem = 'qb' zur QBCore-Nummer zurückkehren.
Einsätze fehlen im MDT oder es kommt kein PopupDen Job in die passende Gruppe in ps-dispatch/config.lua eintragen und im Dienst sein (Config.OnDutyOnly). Danach restart ps-dispatch.
Marker auf Cayo Perico liegen danebenCAYO_SHIFT_Y in ui/app.js anpassen.
Andere Schrift als in der VorschauDie Schrift wird aus dem Internet geladen. Ohne Verbindung nutzt das MDT eine Ersatzschrift.
Regierung landet in einer anderen OberflächeDen Jobnamen sowohl in Config.GovJobs (shared/config.lua) als auch in GovJobs (ui/app.js) eintragen.
Taxi oder Mechaniker sehen das Polizei-MDTDen Jobnamen in Config.TaxiJobs bzw. Config.MechanicJobs (shared/config.lua) und in TaxiJobs bzw. MechanicJobs (ui/app.js) eintragen.
Profilnotizen werden nicht pro Behörde getrenntBeim Start stellt ps-mdt die Tabelle mdt_data automatisch um. Steht in der Konsole eine Fehlermeldung, den Befehl von Hand ausführen: DELETE FROM mdt_data WHERE cid IS NULL; UPDATE mdt_data SET jobtype='police' WHERE jobtype IS NULL OR jobtype=''; ALTER TABLE mdt_data MODIFY cid VARCHAR(20) NOT NULL, MODIFY jobtype VARCHAR(25) NOT NULL DEFAULT 'police', DROP PRIMARY KEY, ADD PRIMARY KEY (cid, jobtype);
Feuerwehr sieht EMS-DatenDer Job muss in Config.FireJobs stehen und darf nicht zusätzlich in Config.AmbulanceJobs stehen.
Vorstrafen werden nicht als Verbrechen erkanntNur Anklagen mit der Klasse „Verbrechen“ oder „Felony“ zählen. Klasse im Katalog prüfen.
